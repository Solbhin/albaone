# 🌟 AlbaOne (알바원)

> Spring MVC 기반 아르바이트 채용 및 근태관리 웹 애플리케이션

사장과 아르바이트생이 하나의 서비스에서 **채용, 근태관리, 전자 근로계약, 급여 계산, 퇴직금 조회**까지 처리할 수 있도록 구현한 웹 애플리케이션입니다.

국비교육 과정에서 진행한 **3인 팀 프로젝트**이며, 저는 **회원 관리, 직원 관리, 채용 공고, 근태 관리, 급여 및 퇴직금 기능**을 담당했습니다.

# 📁 프로젝트 구조

```
src
 ├── controller
 ├── service
 ├── repository
 ├── domain
 ├── exception
 └── resources
```

Spring MVC의 계층형(Layered) 구조를 적용하여 Controller, Service, Repository의 역할을 분리해 개발했습니다.

# 📚 프로젝트를 통해 배운 점

이번 프로젝트를 진행하며 단순히 기능을 구현하는 것을 넘어 Spring MVC 기반의 계층형 구조와 역할 분리의 중요성을 이해할 수 있었습니다.

또한 JDBC를 활용하여 데이터베이스와 웹 애플리케이션을 연동하는 방법을 익혔으며, 근태 관리와 급여 계산처럼 실제 업무에서 활용되는 비즈니스 로직을 구현하는 경험을 쌓았습니다.

프로젝트를 진행하는 과정에서는 ChatGPT를 활용해 필요한 라이브러리와 기술을 빠르게 학습하고 오류를 해결하며 개발 효율을 높였습니다. 생성된 코드를 그대로 사용하는 것이 아니라 직접 검토하고 수정하며 프로젝트에 적용하는 습관을 갖게 되었습니다.

# 🔧 Trouble Shooting

## 1. 급여 계산 기능

### 문제

근무시간에 따라 급여가 달라지기 때문에 계산 로직을 어떻게 구성할지 고민했습니다.

### 해결

출퇴근 기록을 기준으로 근무시간을 계산한 뒤 시급을 적용하여 급여가 자동 계산되도록 구현했습니다.

### 배운 점

단순 계산보다 비즈니스 로직을 코드로 구현하는 과정이 중요하다는 점을 배웠습니다.

---

## 2. 회원 권한 관리

### 문제

고용주와 알바생이 사용하는 기능이 서로 달라 권한을 구분해야 했습니다.

### 해결

회원 유형에 따라 접근 가능한 기능을 구분하여 구현했습니다.

### 배운 점

회원 권한에 따른 서비스 분리가 중요하다는 것을 경험했습니다.

---

## 3. 프로젝트 진행

### 문제

프로젝트를 진행하면서 처음 접하는 기능과 라이브러리가 많았습니다.

### 해결

공식 문서와 ChatGPT를 활용하여 필요한 기술을 빠르게 학습하고 오류를 해결하며 기능을 구현했습니다.

### 배운 점

새로운 기술을 빠르게 익히고 프로젝트에 적용하는 능력이 개발자에게 중요한 역량이라는 것을 느꼈습니다.
